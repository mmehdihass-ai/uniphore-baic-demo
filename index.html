Multi-Agent BPMN Workflows

From Detection to Resolution

Both use cases deploy multi-agent workflows with Human-in-the-Loop checkpoints, ensuring AI autonomy where safe and human oversight where critical.

⚡ Energy Anomaly Response Workflow
⚡
Trigger: Demand Anomaly Detected
Energy Sentinel Agent detects >20% deviation from baseline across any feeder combination
🧠
Root Cause Classification
Model Layer classifies: planned load change, equipment fault, metering error, or genuine overconsumption
📢
Stakeholder Notification
Automated alert dispatched to energy manager with cause, severity, and recommended action
👤
Human Review HITL
Operator confirms, dismisses, or escalates. Agent waits for approval before executing load shed actions
⚙️
Load Optimization Action
Green Factor Optimizer recommends and schedules load shifts; action logged to historian
✓
Resolution Logged & Reported
Sustainability Reporter captures event in daily report; baseline model updated
🌬 Compressed Air Leak Response Workflow
🚨
Trigger: Flow Spike Detected
Leak Detection Agent identifies flow-to-power ratio >2× baseline standard deviation for 15+ minutes
🧠
Severity Assessment
Model quantifies leak magnitude, estimates energy waste per hour, and cross-references pressure drop pattern to narrow location to network zone
📋
Work Order Generation
Work Order Orchestrator auto-drafts maintenance ticket with: timestamp, severity, estimated loss (kWh/h), affected zone, and recommended action steps
👤
Maintenance Manager Approval HITL
Critical events require human authorization before dispatch; manager reviews severity and approves or re-prioritizes
🔧
Maintenance Dispatch
Work order sent to maintenance team; Orchestrator tracks response time and real-time flow normalization
✓
Leak Confirmed Resolved
Flow-to-power ratio returns to baseline; agent auto-closes ticket; total energy waste from event quantified
